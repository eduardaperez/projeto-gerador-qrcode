# 📱 Gerador de QR Code

## Descrição

Este projeto é um **gerador de QR Code** que permite ao usuário inserir qualquer texto, URL ou informação e gerar um **QR Code escaneável** de forma rápida e visual. QR Codes são códigos bidimensionais usados para armazenar informações que podem ser lidas por aplicativos de leitura em celulares e dispositivos — úteis para links, contatos, mensagens e muito mais.

## Tecnologias Utilizadas

- **HTML5** — Estrutura da página  
- **CSS3** — Estilização visual  
- **JavaScript** — Lógica que recebe a entrada do usuário e gera o QR Code  

## Estrutura do Repositório

Organização típica dos arquivos do projeto, que podem ser:

 ```bash

├── index.html ← Página principal
├── css/
│ └── styles.css ← Estilos da página
├── js/
│ └── script.js ← Lógica de geração de QR Code

 ```

## Como Usar

1. Clone o repositório:

   ```bash
   git clone https://github.com/eduardaperez/projeto-gerador-qrcode.git

2. Navegue até a pasta do projeto:

    ```bash
    cd projeto-gerador-qrcode

3. Abra o arquivo index.html no navegador de sua preferência para acessar a interface do gerador QR Code.
4. Digite um texto ou URL no campo indicado, escreva o que você deseja transformar em QR Code.
5. Clique em “Gerar QRCode".
6. O QR Code correspondente será exibido na tela.

## Funcionalidades
1. Gera QR Codes a partir de qualquer texto ou link.
2. Exibe o QR Code na página em tempo real.
3. Permite baixar a imagem do QR Code clicando com o botão direito na imagem gerada.
